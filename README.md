📌 Project Title
Salary Prediction Using Machine Learning – Linear Regression

📝 Project Overview
This project focuses on predicting employee salaries using Machine Learning techniques. The model uses employee-related attributes such as age, years of experience, job title, gender, and education level to estimate salary.
The project was developed using Python and popular Data Science libraries. It includes data loading, data exploration, preprocessing, visualization, model training, and salary prediction using a Linear Regression algorithm.

🎯 Objectives
- Analyze employee salary data.
- Perform data cleaning and preprocessing.
- Convert categorical variables into numerical values using Label Encoding.
- Explore relationships between employee attributes and salary.
- Train a Linear Regression model.
- Predict employee salaries based on input features.
  
🛠️ Technologies Used
- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical computations
- Matplotlib – Data visualization
- Seaborn – Correlation heatmap visualization
- Scikit-learn – Machine Learning model development
- Jupyter Notebook – Project implementation
  
🔍 Project Workflow
1. Data Collection: Loaded the salary_prediction.csv dataset containing 150 employee records.
2. Data Exploration: Used head(), tail(), info(), and describe() to understand the dataset.
3. Data Cleaning: Checked for missing values and performed preprocessing.
4. Feature Encoding: Applied Label Encoding to categorical columns such as Gender, Job Title, and Education Level.
5. Data Visualization: Created a correlation heatmap to explore relationships among numerical features.
6. Feature Selection: Selected Age, Experience, Job Title, Gender, and Education Level as input features.
7. Model Training: Split the dataset into 80% training data and 20% testing data.
8. Model Building: Trained a Linear Regression model using Scikit-learn.
9. Salary Prediction: Generated predicted salary values using the trained model.
    
💡 Key Learnings
- Data preprocessing and feature encoding.
- Exploratory Data Analysis (EDA).
- Handling categorical variables.
- Understanding Linear Regression.
- Training and testing Machine Learning models.
- Making predictions using Scikit-learn.
